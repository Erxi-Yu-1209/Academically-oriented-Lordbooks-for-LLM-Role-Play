# 宏观时空 (`Macro Spacetime`)


[ ← 返回仓库主页 ](../) &nbsp;|&nbsp; [ English ](README.md)

**包含 154 个条目的跨世界观宏观社会学、政治神学、法哲学、政治经济学与“活的世界”动态角色扮演推演总引擎。**


## 一、世界书定位与核心功能

* **对应源文件：** `宏观时空.json`（中文版） / `Macro Spacetime.json`（英文版）
* **条目总数：** **154 个条目**（`5 个常驻激活`核心总控条目 / `149 个关键词触发`二级推演与跨书裁决条目）
* **关联世界书说明：** 本世界书的总控路由（`[CORE:ALL]`）完整保留了 26 套学术框架的转译接口，其中涉及中世纪与早期近代王权双体、新教伦理、宗教裁判所微观史、炼狱空间、卢丹附魔、热沃当怪兽、罗马骑士官僚、控制论政府与条顿军事修会的专门模块已独立拆分并扩充为同仓库的 [中世纪 (Middle Ages)](https://www.google.com/search?q=../Middle-Ages/README-zh.md) 世界书，两者既可单独使用，也可无缝叠加载入。

在构建宏大背景的角色扮演（无论是星际帝国、赛博朋克巨型都市、架空历史共和国还是高魔奇幻大陆）时，大语言模型常常陷入**“宏观与微观脱节”**的困境：要么把朝堂与政变写成小儿科的私人恩怨，无视粮道、财政、科层瞒报与信息延迟；要么生硬堆砌枯燥的设定集黑话，缺乏落到具体人物身上的真实痛感。

**《宏观时空》** 通过 **“5 个常驻总控路由 + 149 个按需唤醒的二级书籍推演模块”** 彻底解决这一问题。它将法理学、政治神学、后殖民东方学、潜隐剧本与高地逃逸理论、社会运动与革命比较史、结构人类学、组织社会学、科学范式革命、结构化理论、场域与惯习、结构主义马克思主义、生命政治及殖民文学中的 18 部核心著作，转化为随时响应剧情关键词的动态叙事规则。

## 二、通用 CoT 总控路由与非单一书籍条目 (`unidentifiable_entries.md`)

严格对照 `unidentifiable_entries.md`，《宏观时空》包含 **8 个无法归属至单一特定出版书籍的系统与原创条目**（4 个 `[CORE:ALL]` 系统路由条目 + 4 个 `[活的世界]` 动态角色扮演条目），以及 **3 个跨书整合裁决器**（同时收录于两份清单备查）：

### A. 常驻系统总控与路由引擎（`[CORE:ALL]` — 4 个常驻条目）
1. **`UID 0` — `[CORE:ALL] 跨世界观宏观叙事总控引擎` (`常驻, @D0, 顺序 100`)**
   * 统合全书学术推演框架，并强制执行**反学术黑话铁律**：严禁把社科理论直接写进角色台词，一切宏观机制必须具象化为人员调动、账册亏空、法令漏洞、地形摩擦、物价波动与对话潜台词。
2. **`UID 1` — `[CORE:ALL] 世界观术语转译器与触发路由` (`常驻, @D0, 顺序 110`)**
   * 在进入不同世界观时，先将本土设定名词转译为底层制度功能，再精准路由至对应模块（如：*教廷律令/龙约/算法协议* → `HART`；*帝国边疆/异族分类/勘探队* → `ORIENT` + `SCOTT`；*法师塔学派/科学危机* → `KUHN:SSR`；*特许殖民商会/魔晶矿站* → `CONRAD:HOD`）。
3. **`UID 2` — `[CORE:ALL] 三层传播与后果账本` (`常驻, @D1, 顺序 120`)**
   * 强制所有宏观事件必须在三个层面同时落地，杜绝高空空转：
     * **直接层（Direct Layer）：** 当事主角、执行官、士兵、书记官、信徒与旁观者的即时身体与利益反应；
     * **制度层（Institutional Layer）：** 法庭、科层衙门、行会、驻军与档案库如何记录、扭曲、瞒报或借机扩权；
     * **日常层（Everyday Layer）：** 粮价起伏、宵禁哨卡、酒馆流言、家庭生计与日常器物的连锁变化。
4. **`UID 74` — `[CORE:ALL] 近场最小机制选择器` (`常驻, @D1, 顺序 130`)**
   * 防止单次回复贪多求全：每轮最多仅挑选 **2–3 个**最契合当前戏剧冲突的宏观机制，并严格维持 **“70% 前景人物感官与行动 + 30% 结构性背景压力”** 的黄金叙事比例。

### B. 原创动态世界推演引擎（`[活的世界]` / `[Living World]` — 1 常驻 + 3 关键词条目）
5. **`UID 218` — `[活的世界] 反全知` (`[Living World] Anti-Omniscience`, `常驻, @D1, 顺序 140`)**
   * 建立严格的**“双盲信息不对称”**门禁：NPC 绝不能偷看玩家的真实状态栏、隐藏身份或内心独白，只能依据流言、伪造文书、衣着口音、阶级偏见与带传输延迟的情报做出反应（包含合理的误判与错怪）。
6. **`UID 215` — `[活的世界] 随机冲突事件生成` (`关键词, @D2, 顺序 395`)**
   * 废除靠掷骰子凭空刷怪的伪随机，一切突发冲突必须是特定空间物理属性（窄巷、集市、封锁线）与多方势力既有时间表碰撞的必然产物。
7. **`UID 216` — `[活的世界] 强关系性与恩怨情仇` (`关键词, @D2, 顺序 396`)**
   * 废除抽象数值好感度，以带历史因果的**“叙事债务账本”**（救命之恩、灭门之仇、把柄要挟、政治联姻）驱动 NPC 态度。
8. **`UID 217` — `[活的世界] 战斗场景` (`关键词, @D2, 顺序 397`)**
   * 废除回合制血条对砍，基于重心控制、动量惯性、体能极限、武器长度与环境障碍构建写实的“动作—反作用”交锋。

### C. 跨书整合危机裁决器（`UID 71–73` — 同时收录于 `identifiable_entries.md` 与 `unidentifiable_entries.md`）
