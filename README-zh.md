# SillyTavern 书籍溯源推演世界书合集 (World Book Repository)


[ English ](README.md) &nbsp;•&nbsp; [ 简体中文 ](README-zh.md)

**将经典学术专著、微观史研究、组织社会学、道德哲学与文学经典转化为 SillyTavern 模块化世界书（Lorebooks）仓库。**


## 仓库简介

在使用 [SillyTavern](https://github.com/SillyTavern/SillyTavern) 进行长篇大语言模型（LLM）角色扮演时，模型往往容易滑向扁平的套路化叙事：庞大帝国运转起来像现代公司公关部，中世纪教会只会喊空洞的宗教口号，复杂的道德两难被一句煽情台词轻易化解，而人物的性别气质与亲密关系则退化为刻板的工业糖精或二元模板。

本仓库收录了 **结构化世界书（`.json`）**，旨在从底层推理机制上解决这一问题。与堆积静态设定词条的传统“百科式世界书”不同，本仓库中的每一部世界书均提炼自具体的正式出版著作——涵盖朱迪斯·巴特勒（Judith Butler）、米歇尔·福柯（Michel Foucault）、厄休拉·勒古恩（Ursula K. Le Guin）、H.L.A.哈特（H. L. A. Hart）、卡尔·施米特（Carl Schmitt）、詹姆斯·C.斯科特（James C. Scott）、皮埃尔·布尔迪厄（Pierre Bourdieu）、恩斯特·康托洛维茨（Ernst Kantorowicz）、马克斯·韦伯（Max Weber）、卡洛·金茨堡（Carlo Ginzburg）、乔纳森·沃尔夫（Jonathan Wolff）以及乔治·赫伯特·米德（George Herbert Mead）等学者的经典著作——并将其改写为**可执行的角色扮演逻辑门、状态账本与二级场景推演模块**。

本仓库中的每一部世界书均由两类条目协同构成：
1. **通用思维链（CoT）与系统总控条目**：包括跨世界观总控路由、本土术语转译器、道德压力门禁、三层传播后果账本、格式塔心理体验循环，以及原创动态世界规则（`[活的世界]`、`[SELF-REASONING]`）。它们负责在后台调度推演模块、严禁学术黑话直接漏入正文对话，并强制执行角色认知边界（如双盲反全知与经验偏置）。
2. **源自特定出版书籍的二级推演条目**：按章节或核心机制从具体书籍中提炼出的领域推演规则。当剧情触发相应关键词时，这些条目会将法学、政治神学、组织社会学、中世纪史、性别表演理论与道德哲学转化为作用于角色肉身、财政账簿、法庭审讯、街巷流言、跨国补给线与微表情姿态的真实叙事压力。

## SillyTavern 世界书运行机制说明

* **常驻条目（`constant: true`，SillyTavern 中显示为 🔵 蓝灯）：** 无论对话内容是什么，每轮生成都会注入上下文。在本仓库中，仅有轻量级的系统总控路由、术语转译器、反全知门禁以及高度凝练的全局引擎（如《性别去刻板印象化 2.0》的 19 个条目）被设为常驻，从而最大限度节省基础 Token 开销。
* **关键词触发条目（`constant: false`, `selective: true`，SillyTavern 中显示为 🟢 绿灯）：** 平时静默存储在本地，仅当用户输入或近期对话中出现匹配的关键词（`key`）时才会被动态挂载进 Prompt。这一设计使得《宏观时空》（154 条）、《中世纪》（88 条）与《道德伦理学 2.1》（72 条）能够容纳数十本学术专著的推演逻辑，而在单次回复中仅精准激活与当前场景相关的 2–5 个模块。
* **注入深度（`depth: 0` 至 `4`）与插入顺序（`order`）：**
  * `@D4` 与 `@D3`（距离最新回复 3–4 条消息处）用于挂载中远场结构性背景与基础学派理论；
  * `@D2` 与 `@D1` 用于挂载近场冲突裁决器、三层后果账本与心理防御机制；
  * `@D0`（紧贴最新一轮生成的底部位置）用于挂载最高优先级的总控门禁与 `<think>` 思维链校验指令。
* **反术语转译原则（Anti-Jargon Translation）：** 本仓库所有世界书均严格区分**后台逻辑计算**与**前台文学叙事**。大模型利用这些条目在后台计算“谁承担制度代价、谁在篡改账目、谁的身体因羞耻而僵硬、哪条补给线正在失血”，但最终输出的永远是符合人物身份与时代语境的感官细节、动作与潜台词，绝不会让角色在对话中背诵现代社科学术名词。

## 世界书功能速览

### 1. 性别去刻板印象化 2.0 (`Gender De-stereotyping 2.0`)
* **详细文档：** [./Gender-De-stereotyping-2.0/README-zh.md](https://www.google.com/search?q=./Gender-De-stereotyping-2.0/README-zh.md) | [./Gender-De-stereotyping-2.0/README.md](https://www.google.com/search?q=./Gender-De-stereotyping-2.0/README.md)
* **架构特点：** 共 19 个常驻条目（`14 条 @D4`，`5 条 @D2`），融合朱迪斯·巴特勒《性别麻烦》《消解性别》、米歇尔·福柯《性经验史（三卷本）》《伦理：主体性与真理》、克里斯托弗·沃特金《雅克·德里达》以及厄休拉·勒古恩《黑暗的左手》与〈性别是必要的吗？〉。
* **核心作用：** 彻底消除大模型将角色简化为“男强女弱/生理本能宿命论”的刻板印象，内置落笔前五步静默检查器（`[BUTLER:CHECKLIST]`）以及面向奇幻/科幻无性别或非父权设定的社会权力推演引擎。

* **核心作用：** 专为宏大政治博弈、帝国边疆、殖民特许公司、社会抗争、政权更替、法师塔/科学院学派之争及政治经济学推演打造。内置术语转译器，自动将奇幻/科幻/历史本土概念映射至底层制度机制，并强制每一项宏观变动同时在直接层、制度层与日常层留下账本后果。
